# 건강 수호자 RPG 개발판 v0.4.0

## 전투 장면 변경

- 화면을 가로질러 날아가던 발사체를 제거했습니다.
- 주인공과 몬스터를 화면 중앙 가까이에 배치하고, 주인공이 짧게 접근해 칼로 직접 공격하도록 바꿨습니다.
- 칼을 위로 드는 동작 대신 옆으로 베는 공격 자세를 사용합니다.
- 몬스터가 맞으면 찌그러지고 뒤로 튕기며 `×﹏×` 말풍선과 별 효과가 나타납니다.
- 주의 습관이 우세할 때도 몬스터가 가까이 돌진하고 주인공이 밀리는 근접 연출을 사용합니다.

## 그래픽 변경

- 기존 캐릭터 모음 이미지를 잘라 표시하던 방식을 없앴습니다.
- 남성·여성 캐릭터의 정지, 공격, 피격, 휴식, 승리 자세를 각각 독립된 투명 PNG 파일로 분리했습니다.
- 각 몬스터도 독립 파일로 분리해 옆 그림이 섞이거나 가장자리가 잘리는 문제를 막았습니다.
- 전투 배경을 모바일 전투 장면에 맞춘 새 픽셀 풍경으로 교체했습니다.

## 기존 기능 보호

- 운영 `index.html`과 운영 식단 기록 기능 변경 없음
- Supabase 테이블·RLS·Edge Function 변경 없음
- RPG 저장 규칙 버전만 `rpg-v0.4.0`으로 기록
- 이전 개발판 `index_v0.3.0.html` 보존

## 이미지 제작 정보

- 새 배경은 내장 ImageGen으로 제작한 뒤 웹용 WebP로 최적화했습니다.
- 최종 프롬프트는 밝은 야외 초원, 먼 산과 구름, 중앙의 비어 있는 근접 전투 공간, 인물·몬스터·글자·UI가 없는 2:1 픽셀 배경을 요청했습니다.
- 기존 캐릭터와 몬스터 원본은 의미를 바꾸지 않고 독립 프레임으로 분리했습니다.
