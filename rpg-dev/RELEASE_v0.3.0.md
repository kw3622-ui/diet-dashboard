# 건강 수호자 RPG 개발판 v0.3.0

## 변경 내용

- RPG 상태를 사용자별로 보관하는 `rpg_profiles` 테이블을 추가했습니다.
- 장비 등급, 내구도와 착용 상태를 보관하는 `rpg_inventory` 테이블을 추가했습니다.
- 음식 하나하나의 질환별 도움·주의 태그를 보관하는 `food_health_tags` 테이블을 추가했습니다.
- 고정된 게임 규칙으로 계산된 보너스·피해·회복 내역을 기록할 `rpg_events` 테이블을 추가했습니다.
- 개발 페이지에서 캐릭터 성별, 레벨, 경험치, HP, 성장 단계, 좋은·주의 흐름과 장비를 저장합니다.
- 캐릭터 성별을 바꾸면 RPG 전용 저장소에 반영되어 다른 기기에서도 같은 캐릭터가 선택됩니다.
- 음식별 태그 저장 건수를 개발 화면에서 확인할 수 있습니다.

## 보안

- 새 테이블 네 개 모두 RLS를 사용합니다.
- `authenticated` 사용자는 자신의 데이터만 조회·추가·수정·삭제할 수 있습니다.
- 음식 태그와 게임 사건은 본인 소유의 기존 식단 기록에만 연결할 수 있습니다.
- `anon` 역할의 접근 권한을 제거했습니다.

## 기존 기능 보호

- `profiles`, `logs`, `daily_reports`, `period_reports` 구조와 데이터 변경 없음
- 운영 `index.html` 변경 없음
- 운영 `diet-ai` Edge Function v13 변경 없음
- 되돌리기 SQL: `migrations/rpg_storage_rollback_v0.3.0.sql`

## 다음 단계

- 저장된 태그를 고정 게임 규칙에 연결
- 일일 검수와 주간 통계에 질환별 도움·주의 횟수 표시
