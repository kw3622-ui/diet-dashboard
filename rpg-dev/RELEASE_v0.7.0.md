# 건강 수호자 RPG 개발판 v0.7.0

## 목적

사용자가 선택한 단순한 저해상도 도트 스타일로 성별 없는 건강 수호자의 초급·최상급 성장 장면을 검토하는 시제품입니다.

## 변경 내용

- 남성·여성 선택 제거
- 얼굴이 보이지 않는 폐쇄형 투구 적용
- 큰 픽셀이 보이는 저해상도 도트 원화 적용
- 초급 가죽·철 장비 수호자와 최상급 흑철 장비 수호자 제공
- 작은 돌멩이와 거대 압력 골렘 제공
- 캐릭터는 중앙, 몬스터는 뒤쪽에 배치
- 공격·피격 애니메이션 없이 정적인 성장 장면 유지
- 기존 10단계 성장 계산은 초급(1~5)과 최상급(6~10) 시제품으로 변환

## 원화 제작

- 내장 이미지 생성 도구로 독창적인 저해상도 픽셀 원화를 제작했습니다.
- 최종 원화는 투명 배경으로 정리하고 모바일 전송 크기에 맞게 축소했습니다.
- 외부 참고 이미지의 캐릭터나 장비는 복제하지 않았습니다.

## 현재 범위

- 이번 버전은 그림체·비율·장면 구도를 확인하는 2단계 시제품입니다.
- 개별 투구·갑옷·장화 교체용 레이어 분리는 그림체 승인 후 다음 제작 단계에서 진행합니다.
- 운영 식단 페이지와 Supabase 스키마는 변경하지 않습니다.

## 검증

- 390×844 모바일 렌더링
- 가로 넘침 0px
- 캐릭터 중앙 오차 0px
- 초급·최상급 이미지 잘림 없음
- 몬스터가 캐릭터 뒤에 표시되는 레이어 순서 확인
- 성별 선택 요소가 남아 있지 않음을 확인
