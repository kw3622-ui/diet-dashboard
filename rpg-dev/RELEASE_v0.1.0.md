# 건강 수호자 RPG 개발판 v0.1.0

## 목적

운영 중인 식단 기록장과 데이터베이스를 변경하지 않고 RPG 화면과 기본 규칙을 검토하기 위한 읽기 전용 개발판입니다.

## 포함 내용

- 기존 계정 로그인과 최근 90일 기록 조회
- 남성·여성 픽셀 캐릭터 선택
- 캐릭터 5단계 외형 성장
- 기록, 식단, 수면, 금주, 운동 기반 장비 5종과 5단계 등급
- 좋은 습관 흐름과 주의 습관 누적
- 기저질환에 맞춘 몬스터 등장
- 현재 흐름에 따른 캐릭터 또는 몬스터 공격 애니메이션
- 체험용 가상 데이터

## 안전 범위

- 운영 `index.html` 변경 없음
- Supabase 테이블과 데이터 변경 없음
- 운영 `diet-ai` Edge Function 변경 없음
- 게임 상태 저장 없음
- AI 호출 없음

## 다음 단계 후보

- 음식별 건강 태그의 데이터 형식 확정
- 누적 보너스·벌점 수치 조정
- 장비와 캐릭터 픽셀 디자인 개선
- 검토 완료 후 RPG 전용 테이블과 저장 기능 추가
