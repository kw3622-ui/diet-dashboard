# 건강 수호자 RPG 개발판 v0.2.0

## 변경 내용

- 캐릭터를 전투 화면 왼쪽, 몬스터를 오른쪽으로 변경했습니다.
- 첨부된 참고 이미지의 SD 비율과 선명한 도트 윤곽만 참고해 독창적인 남성·여성 건강 수호자를 제작했습니다.
- 남성은 청색 계열, 여성은 적색 계열의 서로 다른 캐릭터와 장비를 사용합니다.
- 각 캐릭터에 대기, 공격, 피해, 휴식, 승리의 다섯 동작을 연결했습니다.
- 성장 단계에 따라 캐릭터 크기, 채도, 밝기와 오라가 달라집니다.
- 공격 방향도 왼쪽에서 오른쪽으로 변경했습니다.
- 질환과 생활 습관에 대응하는 건강 몬스터 7종도 같은 도트 스타일로 새로 제작했습니다.

## 안전 범위

- 운영 `index.html` 변경 없음
- Supabase 테이블과 데이터 변경 없음
- 운영 `diet-ai` Edge Function 변경 없음
- 게임 상태 저장과 AI 호출 없음
