# 건강 수호자 RPG 개발판 v0.5.0

## 정적 성장 장면

- 반복되는 공격·피격 애니메이션과 발사체를 사용하지 않습니다.
- 남성·여성 캐릭터를 장비 확인에 적합한 정면형 3/4 자세로 교체했습니다.
- 캐릭터, 무기, 몬스터를 각각 독립 이미지로 표시해 옆 프레임과 칼끝이 섞이거나 잘리지 않습니다.

## 무기 10단계

- 성장 점수에 따라 무기가 `Lv.1~10`으로 올라갑니다.
- 금이 간 나무 막대에서 전설의 용살검까지 단계마다 이름과 외형이 달라집니다.
- 무기 레벨은 전체 기록일, 운동, 수면 목표, 균형 식사 단서를 합친 장기 성장 점수로 계산합니다.
- 무기는 RPG 전용 장비 저장소에 `weapon` 항목으로 저장합니다.

## 압력 골렘 10단계

- 최근 14일의 음주, 나트륨·튀김·야식 단서, 수면 부족과 운동 부족으로 위협 점수를 계산합니다.
- 위협 점수에 따라 수상한 돌멩이부터 압력의 거신까지 `Lv.1~10`으로 변화합니다.
- 과거의 주의 습관을 영구 누적하지 않으므로 생활이 좋아지면 골렘 단계도 다시 낮아집니다.

## 개발판 검토 기능

- 좌우 버튼으로 1~10단계 무기와 골렘을 함께 미리 볼 수 있습니다.
- 미리보기는 저장되지 않으며, 실제 기록 단계로 즉시 돌아갈 수 있습니다.

## 기존 기능 보호

- 운영 식단 페이지 변경 없음
- Supabase 테이블·RLS·Edge Function 변경 없음
- 기존 `v0.4.0` 개발판 보존
- 기존 장비 다섯 종류는 이전 5단계 계산을 유지하고 무기만 먼저 10단계로 적용

## 이미지 제작 정보

- 남녀 정면형 캐릭터, 무기 10단계, 압력 골렘 10단계는 내장 ImageGen으로 제작했습니다.
- 생성된 모음 이미지는 각 개체의 투명 영역을 분리해 독립 PNG로 저장했습니다.
- 유명 게임의 무기나 캐릭터를 복제하지 않은 독창적인 픽셀 디자인을 사용했습니다.
